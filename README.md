# Forest Survival

Браузерная кооперативная 3D-игра о выживании в лесу, вдохновлённая игровым циклом «99 Nights in the Forest» в Roblox.

Репозиторий: https://github.com/Bezinteresa/ForestSurvival

## Текущее состояние

**Планирование завершено. Игровой код ещё не написан.** Первой реализуется задача **T001**. Подробное состояние — в [STATUS](docs/STATUS.md).

Сначала делаем управление, удары и сбор ресурсов на простых геометрических моделях. Затем лагерь, выживание, врагов и исследование. После работающего одиночного цикла — кооператив, комнаты и друзья. Финальный визуал, эффекты и звук добавляются в конце.

## Стек

- **TypeScript + Vite** — клиент, сборка и общие типы.
- **Three.js** — 3D-сцена, камера, модели и отображение мира.
- **Vue 3** — HUD, инвентарь, настройки, лобби и социальные окна.
- **Rapier 3D** — коллизии и кинематический контроллер персонажа.
- **Node.js + Colyseus** — отдельный сервер комнат и синхронизации.
- **PostgreSQL** — учётные записи, друзья и постоянный прогресс на позднем этапе.

Это совместно используемые инструменты: Vue не заменяет Three.js. Three.js работает в отдельном игровом цикле; Vue получает небольшие снимки состояния интерфейса.

Версии зависимостей фиксируем при реализации T001 после проверки совместимости. Пока нет package.json, установочных команд и работающего запуска.

## Ближайший результат

Сначала T001–T005: запускаемый каркас приложения с тестовой сценой. Затем T006–T014: персонаж и камера. Следом T015–T024: топор, дерево и подбираемые ресурсы.

Первый игровой прототип считается готовым после T024. Первый одиночный цикл выживания — после T049. Публичное размещение и подключение платных сервисов не входят в текущий этап планирования.
