# Forest Survival

Браузерная кооперативная 3D-игра о выживании в лесу, вдохновлённая игровым циклом «99 Nights in the Forest» в Roblox.

Репозиторий: https://github.com/Bezinteresa/ForestSurvival

## Текущее состояние

**Реализован T032a — расход сытости при беге.** После коллизий движение под бегом расходует 0,5/с, ходьба/стояние — 0,25/с. Удержание Ctrl на месте, упор в стену и вертикальный прыжок не включают повышенный расход. Сутки T036 сохраняют 180 с дня / 60 с ночи и раздельный зачёт прогресса. Прошли типы, 143 теста и сборка. Базовые браузерные сценарии проверены 2026-10-18; интерфейс T032–T036, освещение, поведение T032a, Pointer Lock в обычном Chrome и реальный телефон ещё требуют проверки. Подробности — в [STATUS](docs/STATUS.md).

Сначала делаем управление, удары и сбор ресурсов на простых геометрических моделях. Затем лагерь, выживание, врагов и исследование. После работающего одиночного цикла — кооператив, комнаты и друзья. Финальный визуал, эффекты и звук добавляются в конце.

Целевое задание уточнено 2026-10-19: 4 спасения, сутки около 4 минут, кровати/дети и множитель x1–x9, костёр до 6, верстак до 3, классы и алмазы. Эти расширения запланированы в [AI_GAME_SPEC](docs/AI_GAME_SPEC.md) и ROADMAP; в текущем коде костёр имеет 3 уровня.

## Стек

- **TypeScript + Vite** — клиент, сборка и общие типы.
- **Three.js** — 3D-сцена, камера, модели и отображение мира.
- **Vue 3** — HUD, инвентарь, настройки, лобби и социальные окна.
- **Rapier 3D** — коллизии и кинематический контроллер персонажа.
- **Node.js + Colyseus** — отдельный сервер комнат и синхронизации.
- **PostgreSQL** — учётные записи, друзья и постоянный прогресс на позднем этапе.

Это совместно используемые инструменты: Vue не заменяет Three.js. Three.js работает в отдельном игровом цикле; Vue получает небольшие снимки состояния интерфейса.

Версии зафиксированы в package.json и package-lock.json. Проверено на Node.js 24.19.0 / npm 11.9.0. Для локальной работы рекомендуется Node.js 24 LTS.

## Запуск

Из корня репозитория:

```bash
npm ci
npm run dev
```

Открыть адрес, который напечатает Vite (обычно http://localhost:5173), и нажать «Открыть поляну». Двойной клик по index.html не заменяет dev-сервер. При первом запуске загружаются отдельные модули 3D и WASM-физики.

```bash
npm run check
npm run build
npm run preview
```

check запускает проверку типов, 143 теста и production-сборку. Готовая клиентская сборка: apps/client/dist/. Сервер Colyseus пока не добавлен.

На другом устройстве в той же сети: npm run dev -- --host 0.0.0.0, затем открыть сетевой адрес из вывода Vite. Это локальная разработка, а не общедоступное размещение.

В сцене: WASD/стрелки — движение относительно камеры; Space — прыжок; Ctrl — бег; ПКМ — обзор; колесо — дистанция до первого лица; Shift — фиксация камеры; Esc — пауза и освобождение указателя. Меню содержит продолжение, повтор, завершение, чувствительность, инверсию Y и debug-коллайдеры.

ЛКМ — применить предмет: удар инструментом или съесть ягоду, в том числе при удерживаемой ПКМ для обзора; E — подобрать выделенный предмет, собрать ягоду, открыть склад или подложить древесину в костёр; 1–5 — слот руки; Tab или «Рюкзак» — инвентарь; G — выбросить весь активный стек. Дерево выдерживает четыре попадания и оставляет три единицы древесины. Подойдите и посмотрите в сторону предмета: появится подсказка подбора.

Рюкзак содержит пять слотов. Топор занимает один, древесина складывается по три: с топором помещается 12 единиц. Пустой слот или древесина оставляют руку без инструмента. Инвентарь позволяет выбрать предмет, перенести/объединить стеки и выбросить их. Подбор принимает весь стек либо сохраняет его на земле. Выброс требует земли под ногами и свободного места перед игроком; инструмент тоже можно выбросить и вернуть с сохранением уровня.

Ящик склада находится рядом со стартом, в точке X=−1,5 / Z=−2. Посмотрите на него и нажмите E/«Склад» или откройте рюкзак рядом. В разделе склада выберите стартовую кирку и нажмите «Забрать в рюкзак». Три удара киркой исчерпывают каменную жилу и дают три камня; два удара разбирают завал и дают два металлолома. Топор не добывает эти материалы, кирка не рубит дерево. «В склад» и «Забрать» переносят весь стек, проверяя место и близость к ящику. Склад пока относится к одиночной LocalSession; сеть не добавлена.

Рядом со стартом куст ягод (X=1,2 / Z=−1,3); всего на поляне четыре куста по три ягоды. Наведитесь и нажмите E/«Собрать»: одна ягода попадёт в рюкзак, полный рюкзак сохраняет запас куста. Ягоды складываются по пять. Выберите их в руку и нажмите ЛКМ/«Есть» либо в рюкзаке «Съесть одну». Ягода восстанавливает до 25 голода; при полной сытости не тратится, HP не лечит. Еду можно выбрасывать, подбирать и хранить на складе.

HP и голод начинаются со 100. Сытость убывает на 0,25/с при ходьбе/стоянии и на 0,5/с при движении с бегом. Учитывается горизонтальное перемещение после коллизий с порогом 0,1 м/с против дрожания: на месте, при полном упоре и прыжке без движения повышенного расхода нет. Движение вдоль стены и горизонтальный прыжок с бегом сохраняют повышенный расход. При нуле сытости снимается 5 HP/с только за голодную часть шага. Без еды и бега истощение начинается на 400 с, смерть — на 420 с; при непрерывном движении с бегом расчётные значения 200/220 с. Меню паузы останавливает симуляцию; открытый рюкзак оставляет базовый расход и очищает движение/бег. После смерти доступны новый забег или выход; новый забег восстанавливает здоровье, кусты, ресурсы и стартовое снаряжение. Враги и лечение пока не добавлены.

Костёр стоит рядом со стартом (X=0 / Z=2,8). На старте 60 с топлива, максимум 180 с. Выберите древесину в руку, наведитесь на костёр и нажмите E/«Топливо» либо откройте рюкзак рядом, выберите древесину и нажмите «В костёр · 1 древесина». Списывается одна единица за +30 с; если целая порция не помещается, древесина сохраняется. Нужны дальность до 2,6 м и прямая видимость; во время удара действие запрещено. Остаток топлива виден при наведении и в рюкзаке. Пока костёр горит, кольцо показывает зону начального радиуса 5 м; при нуле она отключается. Голод и HP от костра не восстанавливаются. Защита от Ночного стража будет подключена вместе с ним в T046. Пауза замораживает топливо, рюкзак оставляет расход включённым.

Рядом с горящим костром откройте рюкзак → «Костёр» → «Улучшить». Уровень 2 стоит 3 древесины + 3 камня и расширяет зону до 7 м; уровень 3 стоит 3 древесины + 3 камня + 2 металлолома и даёт 9 м. Панель показывает имеющиеся и требуемые материалы. Цена списывается целиком из рюкзака; склад нужно предварительно разгрузить вручную. Покупка не добавляет и не тратит топливо, сохраняет его предел 180 с. При затухании уровень остаётся; новый забег возвращает уровень 1.

Сутки занимают 4 минуты игрового времени: день 180 с и ночь 60 с. Вверху видны фаза/номер цикла, время до смены, пережитые физические ночи, зачтённые дни и множитель. Рассвет на 240-й секунде даёт по одной ночи и одному дню; сейчас множитель x1, кровати/спасения появятся позднее. Освещение меняется в течение 10 с у рассвета/заката. Меню замораживает часы, рюкзак оставляет их включёнными. Сброс позиции не меняет прогресс, новый забег начинает с дня 1 и нуля пережитых ночей. Победа по счётчику 99 относится к T079 и ещё не завершает текущий прототип.

На сенсорном устройстве отображаются левый стик, правая область обзора, кнопки «Удар»/«Есть», «Взять»/«Собрать»/«Склад»/«Топливо», прыжок, бег, фиксация и приближение. Предмет выбирается касанием панели, рюкзак открывается кнопкой вверху. Пока окно открыто, игровые действия отключены, курсор свободен, мир продолжает работать. Tab/Esc или «Закрыть» возвращают управление.

Если Pointer Lock недоступен, обзор мышью работает при удержании ПКМ. Первый клик, запускающий захват мыши, не считается применением предмета. После отказа захвата ЛКМ остаётся доступной игровым действиям.

Известное ограничение сборки: чанки Three.js и Rapier превышают 500 кБ. Они загружаются после нажатия запуска; Rapier compat занимает примерно 1,67 МБ gzip. Оптимизация загрузки и измерения на телефоне ещё впереди.

## Проверка улучшений

Обычный запуск не выдаёт улучшений. Для проверки данных уровней в разработке:

```bash
VITE_ENABLE_DEBUG_TOOLS=true npm run dev
```

Альтернатива для любой оболочки: скопировать .env.example в .env.local, установить флаг true и перезапустить Vite. В рюкзаке появится явно обозначенная проверка улучшений. В меню → «Проверка сцены» доступны скорости x1/x5/x20: ускоряются все фиксированные шаги, включая движение, голод и топливо. Удары/подборы от одного нажатия не повторяются. Это отдельный режим диагностики; игровой множитель зачтённых дней остаётся x1. Скорость сохраняется до нового забега, производственная сборка отключает режим независимо от флага. Уровень 2 удваивает урон инструмента и сокращает восстановление; рюкзак расширяется с пяти до восьми слотов. Панель 1–5 показывает первые пять; дополнительные слоты доступны в окне. Production-сборка игнорирует флаг и отключает тестовую выдачу. Обычная покупка/крафт улучшений появятся в T037/T038.

Следующий пункт — T034a: уголь и ночной холод. Затем T035a: костёр до 6; далее крафт и лагерь по ROADMAP. По указанию пользователя разработка продолжается без ожидания его ручной проверки; открытые критерии T011/T013/T014/T027, проверка интерфейса T032–T036 и сценарий T032a перечислены в TESTING.

Первый игровой прототип считается готовым после T024. Первый одиночный цикл выживания — после T049. Публичное размещение и подключение платных сервисов не входят в текущий этап планирования.
