# Проверка первого каркаса

## Автоматические проверки

Из корня репозитория, с Node.js 24 LTS:

```bash
npm ci
npm run check
```

check выполняет vue-tsc/tsc, 11 тестов Vitest с реальным Rapier WASM и Vite production build. Тесты проверяют физические столкновения и жизненный цикл с подменённым планировщиком кадров/представлением. Они не создают браузер, WebGL-контекст и не проверяют пиксели или GPU-память.

## Ручной сценарий T002/T005

```bash
npm run dev
```

1. Открыть адрес из вывода Vite. Видны название и кнопка «Открыть поляну».
2. Нажать кнопку. После загрузки появляется поляна, восемь деревьев, стены и блочный персонаж. Персонаж опускается на землю; индикатор меняется на «На земле».
3. Изменить размер окна, проверить широкий и узкий экран. Canvas занимает доступное пространство, пропорции сцены не искажаются, кнопки доступны.
4. Нажать «Пауза». Время замирает. «Продолжить» возобновляет отсчёт без большого скачка.
5. Открыть «Проверка сцены», включить коллайдеры. Видны контуры пола, стен, стволов и капсулы. Выключение убирает контуры.
6. Нажать «Сбросить позицию персонажа». Персонаж снова опускается на землю; это диагностическая команда, не прыжок.
7. Нажать «Заново» несколько раз. Время начинается с нуля; на странице остаётся один canvas.
8. Нажать «Завершить сцену». Canvas удаляется, возвращается стартовая панель. Повторить полный цикл десять раз и проверить отсутствие накопления canvas, observers, обработчиков и WebGL-контекстов в инструментах браузера.
9. Переключиться на другую вкладку и обратно: локальная сцена остаётся на паузе до явного продолжения.
10. В отдельной проверке отключить WebGL 2 / вызвать потерю контекста инструментами браузера. Должна появиться понятная ошибка и возможность повторить запуск без зависшего loading.
11. Быстро завершить сцену во время первоначальной загрузки через переход/размонтирование приложения (например, HMR). Поздно завершившаяся загрузка не должна оставлять живую сессию или canvas.

Для production-сборки: npm run build, затем npm run preview; повторить основной путь. Открытие dist/index.html через file:// не поддерживается.

## Что пока отсутствует

Передвижение, прыжок, обзор мышью, удары, рубка, инвентарь, полноценное touch-управление и кооператив относятся к следующим этапам. Сейчас используется фиксированная камера и диагностическое падение персонажа.
