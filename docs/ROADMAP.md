# План разработки

Дата исходного плана: 2026-10-18.

Каждая задача содержит способ реализации и наблюдаемый критерий готовности. Выполнять по порядку, небольшими связанными группами. Фактический прогресс и ближайший ID вести в STATUS.md. Незакрытые критерии проверки не отмечать выполненными только по наличию кода.

Числа и названия промежуточные. В начале нет финальных моделей, частиц и сложного оформления. Простые подсказки, индикаторы попадания и читаемые границы нужны сразу для проверки механик.

## Этап 0. Запускаемый каркас — T001–T005

- [x] **T001. Инициализировать проект.** Создать npm workspaces, apps/client, TypeScript, Vite и Vue 3; проверить совместимые версии, зафиксировать lock-файл. **Готово:** чистая установка и сборка пустого приложения проходят; README содержит реальные команды.
- [x] **T002. Встроить Three.js.** Создать canvas, сцену, камеру, renderer, изменение размера и обработку ошибки WebGL. **Готово:** видна тестовая сцена, окно корректно меняет размер.
- [x] **T003. Выделить игровую сессию.** Минимальные Game, LocalSession, ID сущностей, команды и снимок состояния; без реализации сетевого транспорта. **Готово:** UI запускает и завершает LocalSession, не управляя мешами напрямую.
- [x] **T004. Подключить коллизии.** Rapier, фиксированный шаг, пол, несколько стен, капсула игрока и debug-показ коллайдеров. **Готово:** тело не проходит сквозь пол/стены, симуляция не ускоряется с FPS.
- [x] **T005. Сделать тестовую поляну.** Примитивный персонаж, несколько деревьев-заглушек, старт/повтор, очистка ресурсов. **Готово:** можно несколько раз запустить и закрыть сцену без второго цикла и лишних обработчиков.

**Состояние этапа:** T001–T005 реализованы; базовая браузерная проверка T002/T005 выполнена 2026-10-18 (см. STATUS.md). Оставшиеся ограничения окружения перечислены в TESTING.md.

**Промежуточный результат:** запускаемый каркас; игровые действия ещё не считаются готовыми.

## Этап 1. Персонаж и Roblox-подобная камера — T006–T014

- [x] **T006. Создать InputActions.** Move, Look, Jump, Sprint, CameraLock, Primary, Interact, Hotbar, Inventory; контексты Gameplay/UI. **Готово:** действия читаются независимо от конкретных клавиш; меню блокирует игровой ввод.
- [x] **T007. Передвижение.** WASD относительно камеры, нормализация диагонали, плавный разворот персонажа. **Готово:** одинаковая скорость по прямой и диагонали; поворот камеры меняет направление движения.
- [x] **T008. Гравитация и прыжок.** Проверка земли, вертикальная скорость, склоны/ступени. **Готово:** прыжок доступен с земли, приземление устойчиво, стену не перелезают спамом прыжка.
- [x] **T009. Третье лицо.** Следование камеры, ПКМ-обзор, ограничение вертикали, колесо дистанции. **Готово:** камера вращается плавно, стоящий персонаж не обязан поворачиваться вслед за ней.
- [x] **T010. Коллизия камеры.** Проверка препятствий от точки слежения до желаемой позиции. **Готово:** стена не закрывает игрока и камера не уходит за неё.
- [ ] **T011. Shift-lock и первое лицо.** Отдельное действие фиксации направления, Pointer Lock после клика, скрытие мешей у камеры. **Готово:** оба режима работают и Esc возвращает курсор; отказ Pointer Lock обработан.
- [x] **T012. Бег и настройки ввода.** Ctrl для бега, отдельная чувствительность, инверсия Y, локальное сохранение настроек. **Готово:** Shift не запускает бег, раскладка согласована с CONTROLS.
- [ ] **T013. Сенсорное управление.** Стик, область обзора, прыжок и действия, мультитач, touch-cancel. **Готово:** можно одновременно идти, смотреть и прыгать; UI не крутит камеру.
- [ ] **T014. Проверить управление целиком.** Потеря фокуса, открытие меню, низкий FPS, изменение окна, мобильная раскладка. **Готово:** нет залипания клавиш и перемещения в текстовом поле; ограничения проверки записаны.

**Состояние этапа:** код T006–T014 реализован. T009 проверен в браузере 2026-10-18; T011/T013/T014 остаются открыты по Pointer Lock и реальному телефону. 2026-10-19 исправлена комбинация ПКМ + ЛКМ, автоматический сценарий проходит; повторная проверка в браузере добавлена в T014.

По указанию пользователя от 2026-10-18 ручная проверка не блокирует следующий блок T015–T024.

**Промежуточный результат:** управляемый персонаж на полигоне.

## Этап 2. Удары и сбор ресурсов — T015–T024

- [x] **T015. Активный предмет.** Определение инструмента, слот руки и простая модель топора. **Готово:** применение зависит от выбранного предмета; пустая рука не рубит дерево.
- [x] **T016. Цикл удара.** Подготовка → попадание → восстановление; cooldown в конфиге. **Готово:** спам ЛКМ не увеличивает частоту и не создаёт параллельные атаки.
- [x] **T017. Поиск попадания.** Сектор/shape query перед персонажем, дистанция и видимость. **Готово:** цель сзади или за стеной не получает удар.
- [x] **T018. Общая обработка воздействия.** DamageInfo и получатели для манекена и ресурсного объекта. **Готово:** один удар повреждает каждую разрешённую цель не более одного раза.
- [x] **T019. Минимальная обратная связь.** Взмах без финальной анимации, краткая индикация попадания и HP манекена. **Готово:** видно момент и результат удара.
- [x] **T020. Наведение взаимодействия.** Выбор доступной цели, подсветка и текст действия E. **Готово:** дальняя цель и цель за препятствием не выбираются.
- [x] **T021. Рубка дерева.** Запас ресурса, подходящий инструмент, истощение и отключение коллизии. **Готово:** после нужного числа ударов дерево исчерпывается один раз.
- [x] **T022. Предмет в мире.** Создать древесину с уникальным ID и простым отображением; без дорогой физики каждого бревна. **Готово:** из одного дерева появляется ровно заданное количество.
- [x] **T023. Подбор.** E отправляет команду LocalSession; минимальный контейнер ресурсов и HUD количества. **Готово:** предмет исчезает только после успешного зачисления; повтор команды не выдаёт его снова.
- [x] **T024. Проверить первую игровую цепочку.** Подойти → ударить → срубить → подобрать → повторить. **Готово:** цепочка работает на ПК и доступном touch-сценарии; есть проверки повторного попадания и повторной выдачи.

**Состояние этапа:** T015–T024 реализованы; T019/T024 закрыты после браузерной проверки ПК и touch-эмуляции 2026-10-18. Настоящий телефон проверяется в T013/T014. См. STATUS.md и TESTING.md.

**Первый игровой прототип:** передвижение, удары и добыча древесины; проверен на ПК и в touch-эмуляции; реальный телефон остаётся в ручном сценарии.

- [x] **T026. Инвентарь Vue.** Открыть, закрыть, увидеть состав и перенести между слотами. **Готово:** окно соответствует состоянию сессии и не принимает боевые клики.
- [ ] **T027. Панель быстрого доступа.** Клавиши 1–5 и touch, активный слот. **Готово:** рука и действие соответствуют выбранному слоту.
- [x] **T028. Выброс и повторный подбор.** Команда G создаёт предмет перед игроком на доступной поверхности. **Готово:** количество сохраняется; нет копии в рюкзаке и мире одновременно.
- [x] **T029. Камень и металлолом.** Разные ресурсные узлы, подходящие инструменты и таблицы выхода. **Готово:** неподходящий инструмент не добывает запрещённый ресурс.

- [x] **T031. Общий контейнер.** Склад лагеря, команды переноса и базовый UI. **Готово:** все операции сохраняют суммарное количество; отмена не меняет содержимое.

## Этап 4. Лагерь и базовое выживание — T032–T040

- [x] **T032. Параметры игрока.** HP, голод, смерть и базовый HUD. **Готово:** значения ограничены диапазоном; нулевое HP вызывает состояние смерти один раз.
- [x] **T033. Питание.** Ягоды и простая еда, команда использования, расход по времени. **Готово:** еда расходуется один раз и восстанавливает голод в пределах лимита.
- [ ] **T034. Топливо костра.** Подкладывание древесины, расход и включение/выключение защиты. **Готово:** ресурс списывается атомарно; потухший костёр убирает безопасную зону.
- [ ] **T035. Уровни костра.** Отдельная цена улучшения, радиус и условия открытия. **Готово:** топливо и уровень не смешаны; покупка расширяет обозначенную зону.
- [ ] **T036. День и ночь.** Игровые часы, фазы, номер ночи, диагностический ускоренный режим. **Готово:** ночь засчитывается на рассвете; все таймеры зависят от одного времени сессии.
- [ ] **T037. Верстак и рецепты.** Список доступных рецептов, проверка ингредиентов и места. **Готово:** цена и результат обрабатываются вместе; неуспешный крафт ничего не теряет.
- [ ] **T038. Уровни верстака.** Открыть улучшенный топор, кирку, рюкзак и первые постройки реальными рецептами. **Готово:** существует достижимая цепочка добыча → крафт → более эффективная добыча.
- [ ] **T039. Готовка и лечение.** Сырое/готовое мясо, место приготовления, бинт. **Готово:** готовка имеет время и понятный результат; лечение не превышает maxHP.
- [ ] **T040. Постройка лагеря.** Предпросмотр склада/баррикады, проверка цены, пересечений и проходов. **Готово:** нельзя строить внутри игрока/костра, за границей размещения и перекрывать единственный выход.

**Состояние T032–T033:** критерии диапазона параметров, однократной смерти и расхода еды проверены автоматически; написаны HUD и экран завершения. Конечный запас кустов, отказ без потери еды, пауза и новый забег покрыты тестами. Проверка отображения кустов/HUD/экрана смерти на ПК и телефоне остаётся открытой в TESTING.md; отметки выше относятся к реализации и логическим критериям. Следующий код — T034.

## Этап 5. Враги и первые три ночи — T041–T049

- [ ] **T041. Базовый AI.** Idle/patrol/pursue/attack/return/dead, разнесённые проверки обнаружения. **Готово:** один волк находит цель и возвращается при потере.
- [ ] **T042. Навигация.** Проходимая сетка по коллайдерам, простой A*, обновление при постройках. **Готово:** волк обходит дерево/баррикаду; недоступная цель не вызывает бесконечный поиск.
- [ ] **T043. Атака моба.** Подготовка, дистанция остановки, cooldown, проверка попадания. **Готово:** моб не толкает игрока непрерывно и не бьёт издалека/сквозь стену.
- [ ] **T044. Смерть и дроп.** Урон игрока мобу, однократная смерть и добыча. **Готово:** мёртвый моб не атакует и не создаёт несколько комплектов лута.
- [ ] **T045. Охота.** Мирное животное, убегание, мясо; затем медведь по общей системе. **Готово:** еду можно добыть, приготовить и употребить без debug-выдачи.
- [ ] **T046. Ночной страж.** Ночная активация, преследование, граница света, возврат на рассвете. **Готово:** работающий костёр защищает от него; обычный топор не убивает стража.
- [ ] **T047. Налёт на лагерь.** План спавна, общая цель группы, ограничение живых врагов. **Готово:** одна небольшая группа приходит и заканчивает бой; спавн не дублируется.
- [ ] **T048. Поражение и повтор.** Одиночная смерть, итоговый экран, новый забег с чистым состоянием. **Готово:** после повтора нет старого лута, AI и таймеров.
- [ ] **T049. Вертикальный срез на три ночи.** Добыча → еда → костёр → крафт → оборона → результат. **Готово:** забег можно завершить победой/поражением без консоли; критические ошибки исправлены.

**Первый цельный одиночный цикл.** Только после этого подключаем полноценную сеть; оставшиеся T050–T057 подготавливают общий мир.

## Этап 6. Мир и исследование — T050–T057

- [ ] **T050. Генерация по seed.** Детерминированные описания объектов с ID и версия генератора. **Готово:** один seed даёт одинаковую исходную карту в двух сессиях.
- [ ] **T051. Гарантии генерации.** Стартовый лагерь, запас базовой еды/дерева, проходы и допустимые точки появления. **Готово:** набор тестовых seed не создаёт заблокированный старт.
- [ ] **T052. Точки интереса.** Хижина, завал, заброшенный лагерь; контейнеры и таблицы лута. **Готово:** контейнер открывается один раз и хранит состояние.
- [ ] **T053. Пояса прогрессии.** Уровни костра/экипировки ведут к более опасным местам и материалам. **Готово:** видна цепочка хотя бы из двух открытий без мгновенного получения всего.
- [ ] **T054. Карта и ориентиры.** Показ лагеря, исследованных мест и доступных целей. **Готово:** игрок находит дорогу обратно без знания координат разработчика.
- [ ] **T055. Задача спасения.** Охраняемая цель, выполнение и однократная награда. **Готово:** цель можно завершить и увидеть подтверждение; награда не повторяется.
- [ ] **T056. Возобновляемые ресурсы.** Саженцы/восстановление дерева по времени, предел активных источников. **Готово:** долгий забег не исчерпывает древесину безвозвратно.
- [ ] **T057. Снимок изменённого мира.** Seed плюс истощённые источники, постройки, предметы, контейнеры и фаза времени. **Готово:** восстановленная LocalSession совпадает с сохранённым состоянием.

## Этап 7. Colyseus и кооператив — T058–T067

- [ ] **T058. Сервер и общие сообщения.** apps/server, Colyseus GameRoom, packages/shared, валидация входных данных. **Готово:** два реальных клиента подключаются к локальному серверу и имеют разные sessionId.
- [ ] **T059. ColyseusSession.** Подключение по ID комнаты через технический экран; контракт LocalSession сохраняется. **Готово:** один и тот же UI показывает подтверждённое состояние локальной/сетевой сессии.
- [ ] **T060. Другие игроки.** Передача позиции/ориентации/действия, интерполяция, лимиты частоты/скорости. **Готово:** два клиента видят движение и предметы друг друга; произвольные координаты отбрасываются.
- [ ] **T061. Общие ресурсы и инвентари.** Серверные операции добычи, подбора, выброса, переноса и крафта. **Готово:** два клиента не забирают один ID; повтор запроса не создаёт ресурсы.
- [ ] **T062. ИИ на лидере.** simulationHostId, только один исполняемый AI; остальные интерполируют принятые сервером снимки. **Готово:** один моб одинаково отображается у участников, второй AI на госте не запускается.
- [ ] **T063. Общий бой, время и лагерь.** Сервер подтверждает HP/смерть/дроп/костёр и таймеры; хост предлагает атаки мобов. **Готово:** два игрока видят одинаковый исход боя и одну выдачу добычи.
- [ ] **T064. Кооперативная смерть.** Поверженное состояние, поднятие бинтом, наблюдение и поражение команды. **Готово:** один участник поднимает другого, одновременная гибель завершает забег один раз.
- [ ] **T065. Переподключение.** Токен reconnect, срок удержания места, полный снимок, восстановление UI. **Готово:** обрыв/возврат не создают копию игрока и не восстанавливают потраченные предметы.
- [ ] **T066. Передача AI-хоста.** Heartbeat, pause, выбор нового клиента, hostEpoch, снимок и ready-подтверждение по ARCHITECTURE. **Готово:** закрытие и зависание вкладки лидера не дублируют AI/урон; старый хост не может писать после возврата.
- [ ] **T067. Сетевые испытания и запуск.** 2–4 клиента, задержка/потери, истощение ресурсов, полная партия, отсутствие подходящего хоста; инструкция Node.js/WSS. **Готово:** подтверждён кооперативный сценарий и все ограничения; стоимость/сервис хостинга не считаются выбранными автоматически.

**Сеть готова к игровому лобби только после реальных проверок T061–T067.**

## Этап 8. Лобби, друзья и сохранения — T068–T075

- [ ] **T068. Комнаты.** Список публичных, создание, приватная комната и присоединение по коду; проверки доступа на сервере. **Готово:** нельзя войти в заполненную/закрытую комнату или обойти приватность через запрос.
- [ ] **T069. Партия перед стартом.** Участники, ready, лидер, настройки и общий переход в забег. **Готово:** старт происходит один раз и только при выполненных условиях.
- [ ] **T070. Устойчивая личность.** Выбрать и реализовать авторизацию, userId, миграции PostgreSQL, серверную сессию. **Готово:** пользователь возвращается в свой профиль; ник не позволяет присвоить чужой аккаунт.
- [ ] **T071. Настоящие друзья.** Поиск по коду, запрос, принятие/отказ, удаление и блокировка. **Готово:** изменения видны двум аккаунтам и сохраняются после перезапуска.
- [ ] **T072. Приглашения внутри игры.** Статус доступности, приглашение друга, принятие/отмена, срок действия и проверка места. **Готово:** приглашение приводит в правильную комнату и обрабатывает уже начатый/полный забег.
- [ ] **T073. Постоянный профиль.** Результаты, достижения и открытые возможности; сервер начисляет награду по ID завершения. **Готово:** повтор завершения не увеличивает награду; клиент не меняет профиль напрямую.
- [ ] **T074. Checkpoint забега.** Версионированное серверное сохранение, согласованный момент снимка и восстановление после рестарта сервера. **Готово:** не возрождаются срубленные деревья/убитые мобы и не копируется выданный лут.
- [ ] **T075. Полный социальный сценарий.** Два аккаунта → друзья → приглашение → ready → забег → reconnect → результат → новый вход. **Готово:** весь путь проходит без ручной правки данных.

## Этап 9. Прогрессия, баланс и полный забег — T076–T081

- [ ] **T076. Таблица баланса.** Добыча/минуту, вместимость, стоимость рецептов, расход топлива/еды, HP/урон/TTK и темп открытия. **Готово:** все ключевые числа собраны в конфиге и есть замеры базового цикла.
- [ ] **T077. Постоянные открытия.** Базовая роль, несколько достижений и небольшие специализации по GAME_DESIGN. **Готово:** открытия приходят из подтверждённых результатов, базовая роль пригодна для соло.
- [ ] **T078. Масштаб сложности.** Зависимость спавнов и ресурсов от ночи/числа участников, ограничения одновременных мобов. **Готово:** соло и команда могут завершить одинаковый короткий сценарий без тупика.
- [ ] **T079. Полные 99 ночей.** Кривая событий и наград, корректное условие победы, ускоренная симуляция для проверки границ. **Готово:** 99-я ночь завершает забег один раз; также пройден обычный игровой тест, ускоренный прогон его не заменяет.
- [ ] **T080. Экономика прогрессии.** Проверить источники/расход материалов, редкие компоненты, накопление и полезность улучшений. **Готово:** отсутствуют очевидные бесконечные циклы выдачи и бесполезные обязательные покупки.
- [ ] **T081. Тесты с игроками.** Короткое обучение и несколько наблюдаемых забегов, список проблем по частоте/влиянию. **Готово:** исправлены основные непонятные действия, ранние смерти и провалы темпа.

## Этап 10. Финальный визуал, эффекты и выпуск — T082–T090

- [ ] **T082. Утвердить стиль.** Несколько согласованных образцов персонажа, леса, лагеря и ночи с учётом бюджета мобильного WebGL. **Готово:** есть единый визуальный ориентир; ранее используемые примитивы можно заменять по частям.
- [ ] **T083. Персонажи и предметы.** Собственные/разрешённые модели и анимации ходьбы, ударов, переноски и смерти. **Готово:** новые модели используют готовые игровые контракты и не меняют попадания.
- [ ] **T084. Окружение.** Лес, точки интереса, лагерь, освещение, туман и читаемая ночь. **Готово:** важные угрозы и ресурсы различимы на низком качестве.
- [ ] **T085. Эффекты и звук.** Костёр, попадания, рубка, шаги, ночь и угрозы; пулы повторяющихся эффектов. **Готово:** эффекты не выдают лишний лут/урон и не накапливаются после повторного старта.
- [ ] **T086. Финальный UI.** HUD, рюкзак, крафт, комнаты, друзья и настройки; понятные состояния загрузки/ошибок. **Готово:** основной путь доступен мышью и touch без наложений.
- [ ] **T087. Производительность.** Instancing растительности, дальность, LOD, ограничение теней/pixelRatio, измерения CPU/GPU/сети. **Готово:** записаны реальные FPS и нагрузка на ПК и выбранном телефоне; целевой ориентир 60/30 FPS не объявляется достигнутым без замера.
- [ ] **T088. Надёжность сборки.** Установка с нуля, CI для типов/сборки/ключевых правил, миграции и резервное копирование. **Готово:** повторяемая клиентская и серверная сборка и документированное восстановление данных.
- [ ] **T089. Тестовое размещение.** Выбранные фронтенд-хостинг, Node.js/WSS и БД, env, healthcheck и проверка двух внешних клиентов. **Готово:** есть фактически доступная тестовая ссылка и работает сеть вне localhost.
- [ ] **T090. Приёмка версии.** Новая партия, все базовые ресурсы, смерть/победа, друзья, reconnect, выход хоста, сохранения и телефон. **Готово:** нет блокирующих дефектов, известные ограничения перечислены, версия помечена и готова к отдельному решению о публичном выпуске.

## Правило изменения плана

Новые задачи добавлять с отдельными стабильными ID или подпунктами, не переименовывать выполненные ID ради красивого порядка. При изменении объёма обновить STATUS и зависимости. Не добавлять визуальные полировки в текущую задачу, если они не нужны для проверки её механики.
