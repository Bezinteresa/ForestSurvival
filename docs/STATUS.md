## Принятые пользовательские требования

1. Веб-игра по игровому опыту «99 ночей в лесу» в Roblox.
2. Вначале персонаж, удары и сбор ресурсов.
3. Управление по принципам Roblox.
4. Кооператив через Colyseus; мобы рассчитываются на клиенте создателя комнаты / лидера партии.
5. Лобби, создание комнат, добавление друзей.
6. Визуал, эффекты и финальное оформление — после механик.
7. Исходники, план и инструкции сохраняются в Bezinteresa/ForestSurvival.

## Рабочие решения, которые можно уточнять во время разработки

- Партия: 1–4 игрока в первой версии; лимит хранится в конфиге.
- Первое испытание полного цикла: три ночи. Полная цель: 99 пережитых ночей.
- Прогресс внутри забега: инструмент, рюкзак, оружие, костёр, верстак, постройки и исследование.
- Постоянный прогресс позже: профиль, достижения, открытые роли и косметика.
- Точные цены, тайминги, HP, урон, скорости и награды пока не утверждены.
- Хостинг фронтенда, Colyseus и базы пока не выбран и не подключён.
- Поддержка телефона включена в план; основной первый сценарий проверки — ПК.

Это проектные решения для нашей адаптации, а не утверждения о точных правилах текущей версии Roblox-оригинала.

## Запуск и проверки

Из корня: npm ci, затем npm run dev. В браузере открыть адрес Vite и нажать «Открыть поляну». Сборка: npm run build; полный набор проверок: npm run check.

Проверено на Node.js 24.19.0 / npm 11.9.0:

- npm ci --no-audit --no-fund: установка с нуля успешна.
- npm run check: типы, 11 тестов и production-сборка прошли.
- Реальная WASM-физика: падение и приземление капсулы, столкновение со стеной.
- Одинаковый ход симуляции при 30/60/144 кадрах рендера в секунду.
- Ограничение догоняющих шагов после долгой остановки, pause/resume без скачка времени.
- Отсутствие двух циклов при повторном старте и освобождение сессии в 10 последовательных запусках.
- Повтор одной команды не сбрасывает позицию второй раз; снимки не дают изменить состояние сессии.

Ограничения: браузерное управление в текущем окружении недоступно. Dev-сервер для автоматической браузерной QA не запускался. Изображение, resize, мобильная раскладка, WebGL-ошибки и реальное освобождение DOM/GPU не проверены. Эти критерии остаются открытыми.

Сборка предупреждает о крупных чанках Three.js (~545 кБ) и Rapier (~4,33 МБ; ~1,67 МБ gzip). Загрузка отложена до старта сцены. Предупреждение не скрыто; мобильная производительность ещё не измерялась.

Точный ручной сценарий — в TESTING.md. Тестовая ссылка не опубликована; на этой итерации исходники сохраняются в GitHub.
