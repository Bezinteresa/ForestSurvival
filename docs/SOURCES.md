# Источники и основания решений

Проверено 2026-10-18. При внедрении конкретной зависимости повторно проверить официальные API и совместимые версии.

## Референс

- Официальная страница Roblox: https://www.roblox.com/games/79546208627805/99-Nights-in-the-Forest
  Подтверждает исходный референс и совместное строительство лагеря. Страница не является полным описанием правил, управления, экономики или классов.

Механики GAME_DESIGN — предложенная спецификация нашей адаптации. Не считать её точной документацией всех действующих механик оригинальной игры.

## Клиент

- Three.js, Making a Game: https://threejs.org/manual/pages/game.html
  Three.js — библиотека 3D-отображения; ввод, физика, поиск пути и правила игры требуют отдельных систем.
- Vue 3, Introduction: https://vuejs.org/guide/introduction.html
  Компонентный интерфейс, реактивность и рекомендуемый для приложений Composition API.
- Rapier, JavaScript character controller: https://rapier.rs/docs/user_guides/javascript/character_controller/
  Кинематическое движение, препятствия, склоны и ступеньки.

Выбор Three.js + Vue + Rapier — архитектурное решение проекта, а не обязательное требование этих библиотек.

## Сеть

- Colyseus State Synchronization: https://docs.colyseus.io/state
  Общее состояние изменяет сервер; клиент отправляет запросы и получает состояние.
- Colyseus Relay Room: https://docs.colyseus.io/room/relay
  Встроенный RelayRoom пересылает сообщения, имеет минимальное состояние и не выполняет авторитетную проверку.
- Colyseus Reconnection: https://docs.colyseus.io/room/reconnection
  Восстановление соединения и разрешение reconnect на стороне комнаты.

ИИ на выбранном клиенте, hostEpoch, миграция симуляции, атомарные игровые операции, друзья и постоянные сохранения — наша дополнительная логика поверх Colyseus. Нельзя обещать эти возможности только по факту подключения библиотеки.
